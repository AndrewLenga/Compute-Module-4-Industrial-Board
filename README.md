# Compute-Module-4-Industrial-Board
Electrical control logic and schematic design of a CM4

This project features a custom Raspberry Pi Compute Module 4 (CM4) industrial carrier board designed with robust power management (12V–24V DC input, protection) and essential communication interfaces, including two protected RS485 channels, Ethernet, UART, SPI, and I2C. The design focuses on industrial reliability, incorporating high-voltage protection on RS485 lines, status LEDs, and optimized PCB layout considerations like impedance control and thermal management for the mezzanine connector interface. The repository includes KiCad/EDA schematics
